# Middle East Dry Fruits CO - Power BI Dashboard Project
This project analyzes the sales and profit data of a *Middle East Dry Fruits Company* using Power BI to create interactive reports and custom dashboards. It showcases advanced DAX functions and best practices for report design and sharing, providing actionable insights into business performance.

![PowerBI_Logo](https://github.com/sreechub/Power_BI_Project/blob/main/download.jpeg)

## Objective
The objective of this project is to demonstrate proficiency in importing, cleaning, and visualizing data using Power BI. Key tasks include:

1. *Importing and cleaning data* from various sources to ensure accurate and meaningful insights.
2. Creating *interactive reports and dashboards* to facilitate data exploration and decision-making.
3. Designing *custom charts and graphs* for a more tailored and informative presentation of data.
4. Applying *DAX functions* to perform advanced calculations and enhance the analytical capabilities of reports.
5. Adhering to best practices for report design and sharing, ensuring reports are user-friendly, efficient, and easily distributable.

## Dataset
This includes **3005 entries** and **8 features** :
1. **Sales person** - Name of the sales person
2. **Geography** - List of countries
3. **Product** - Name of the products
4. **Date** - Date of purchase
5. **Amount** - Price of product
6. **Customers** - Number of customers
7. **Boxes** - Number of box purchased
8. **Cost** - Profit attained

## Conclusion
To conclude, this project effectively demonstrates how Power BI can be used to analyze and visualize key sales and profit metrics for a Middle East Dry Fruits Company. The insights gained through custom dashboards and DAX calculations offer valuable support for strategic business decisions and performance improvements.
